# Virtual Assistant (MERN Stack)

A virtual assistant web application built using MERN stack that helps users with task automation and quick responses.

## 🚀 Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## ⚙️ Installation
```bash
git clone https://github.com/hyndavi-sai/virtual-assistant.git
cd virtual-assistant
npm install
npm start
